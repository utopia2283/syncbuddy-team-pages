# SyncBuddy / Dong Feng · Brand Spec
> Collected: 2026-05-08
> Applied via Huashu-Design workflow fallback for a high-fidelity static product site.

## Core Assets

### Logo
- Primary: `logo.png`
- Usage: header identity and favicon.

### Product Surface
- Static interactive Dong Feng demo: `demo/index.html`
- Console surface: `demo/console.html`
- The homepage should point users to demo surfaces instead of explaining every feature in marketing copy.

### Founder Assets
- Photos are used only as non-clickable public team portraits:
  - `carine-photo.jpg`
  - `profile-photo.jpg`
  - `calvin-photo.jpg`
  - `kenneth-photo-cropped.jpg`
- Founder namecard routes remain deployed for QR/direct links, but the public team section must not link to them.

## Visual Direction
- Philosophy: information architecture + product operating system.
- Tone: precise, commercial, Hong Kong SME decision infrastructure.
- Palette: warm white, ink navy, SyncBuddy teal, restrained gold/red signal accents.
- Avoid: generic purple SaaS gradients, decorative bokeh/orbs, landing-page fluff, public links to private namecards.
